# Network Packet Analyzer

A custom network traffic analysis tool built in Python.

## What This Project Does
This project explores low-level networking concepts by capturing and inspecting network traffic. 

In this initial release, the focus was on building the core logic from scratch:
- Capturing raw network packets.
- Manually unpacking binary packet headers (Ethernet frames, IP headers, TCP/UDP ports).
- Extracting low-level protocol fields directly from raw packet bytes.
